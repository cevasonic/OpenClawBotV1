## 🤖 Cấu hình Model mặc định cho Telegram Chat
- **Yêu cầu:** Thiết lập mặc định chat Telegram sử dụng model `nvidia/nemotron-3-super-120b:free`.
- **Triển khai:**
  1. Phát hiện gateway service chạy với `HOME=/opt/openclaw` và nạp cấu hình từ `/opt/openclaw/.openclaw/openclaw.json`.
  2. Thiết lập `agents.defaults.model.primary` của gateway thành `openrouter-nvidia/nvidia/nemotron-3-super-120b-a12b:free`.
  3. Đồng thời cấu hình các model fallbacks (`step-3.5-flash`, `gemma-4-31b-it`, `deepseek-v4-flash`, `nemotron`) cho gateway.
  4. Thực hiện `systemctl restart openclaw-gateway.service`.
- **Kết quả:** Gateway đã khởi động lại và tải thành công model mặc định: `[gateway] agent model: openrouter-nvidia/nvidia/nemotron-3-super-120b-a12b:free`.
